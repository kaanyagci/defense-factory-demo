# Invoice export service

The invoice service stores invoices for multiple organizations and provides a CSV export API. Members authenticate with individual API credentials and can access their organization's invoices. API credentials are generated by an administrator and only their hashes are stored in the database.

## Run locally

```sh
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python manage.py seed
python manage.py issue-token alice
python app.py
```

The `issue-token` command prints a credential once. Keep it private. To request an invoice, replace `<token>` with Alice's credential:

```sh
curl -H 'Authorization: Bearer <token>' \
  http://127.0.0.1:5000/api/organizations/acme/invoices/inv-100/export
```

The SQLite database is stored in `data/invoices.sqlite3` by default. Set `INVOICE_DB_PATH` to choose another location. The `seed` command adds example records without overwriting existing invoices.

## Run the service in a container

Build the image from this directory. Mount a persistent volume at `/var/lib/invoices`, provision users with the administrative command, and run the service behind a TLS-terminating reverse proxy. Gunicorn serves the application on port 8000.
